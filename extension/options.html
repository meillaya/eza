eza clipper

Add the current page to your eza library, and see when a page is already saved. Create a capture token in eza under Account → Tokens with the capture scope, then paste it here.

Page text

How access works

The extension asks the browser for permission to contact only the server origin you configure. The capture token is stored in this browser profile and sent only in the Authorization header. It is never placed in a URL, a page, or a log.

If adding fails with an access error, press Grant access, or save the options again after the prompt appears.

What is sent to the server

The address and title of the active page are sent to your server to check whether it is already saved. When you add a bookmark, the title and optional tags are sent. Page text is read and sent only when you choose Add page text or Add selection.

Keyboard shortcuts

Ctrl+Shift+Y adds the current page, Ctrl+Shift+U adds the selected text (Command on macOS). Rebind them on the browser's extension shortcuts page.
