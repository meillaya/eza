eza clipper

v0.1.0

Save pages and selections to your eza library. Create a capture token in eza under Account → Tokens with the capture scope, then paste it here.

How access works

The extension asks Chrome for permission to contact only the server origin you configure. The capture token is stored in this browser profile and sent only in the Authorization header. It is never placed in a URL, a page, or a log.

If saving fails with an access error, press Grant access, or re-save the options after the prompt appears.

Keyboard shortcuts

Ctrl+Shift+Y saves the whole page, Ctrl+Shift+U saves the selection (Command on macOS). Rebind them at chrome://extensions/shortcuts.
